SNS Application

XのようなSNSアプリを個人開発しています。 ユーザー認証、投稿、画像投稿、いいね、コメント、 返信、フォローなど、SNSの基本的な機能を実装しています。

主な機能

  • ユーザー登録・ログイン
  • 投稿・画像投稿
  • いいね
  • コメント・返信
  • フォロー・フォロワー
  • プロフィール
  • 投稿削除
  • 無限スクロール
  • 仮想スクロール

Technology

React TypeScript Vite Tailwind CSS Hono Cloudflare Workers Cloudflare D1 Supabase

Technical Point

投稿一覧取得時に、投稿ごとにいいね情報を取得するのではなく、 like_count と is_liked を 投稿データとまとめて取得することで、 APIのN+1問題を改善しました。

また、react-virtuoso を使用した 仮想スクロールを実装し、大量の投稿を効率的に 表示できるようにしています。
